Token launch radar: every pre-token DeFi protocol on the DefiLlama snapshot, ranked by an implied value calibrated from the market caps of live-token peers in the same category, with a concrete farm plan for each one. Wrapped, staked and bridged products of tokens that already trade are kept off the board; the dashboard is sortable, filterable and shows a model breakdown and farm plan per protocol.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input <snapshot.json>
```
